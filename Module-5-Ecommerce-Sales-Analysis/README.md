# Module 5 – E-Commerce Sales Analysis

## Overview

This project analyzes an e-commerce sales dataset to understand
sales patterns, product performance, regional performance, and
business insights.

## Objectives

- Explore and clean the dataset
- Analyze sales and profit
- Analyze categories and sub-categories
- Analyze regional performance
- Identify profitable and loss-making products
- Create meaningful visualizations
- Generate business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Files

- E-Commerce-Sales-Analysis.ipynb
- SampleSuperstore.csv

## Outcome

The project demonstrates how exploratory data analysis and
visualization can be used to transform raw e-commerce data into
meaningful business insights.
