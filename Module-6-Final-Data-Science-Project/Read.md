# Module 6 – Customer Churn Prediction

## Overview

This is the final Data Science project of the internship.

The project analyzes customer data to understand churn behavior
and builds a Machine Learning model to predict customer churn.

## Objectives

- Explore the customer dataset
- Clean and preprocess the data
- Perform Exploratory Data Analysis
- Visualize customer behavior
- Identify factors related to churn
- Build a Machine Learning classification model
- Evaluate model performance
- Generate business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning

A Logistic Regression model is used for customer churn prediction.

## Files

- Customer-Churn-Prediction.ipynb
- WA_Fn-UseC_-Telco-Customer-Churn.csv

## Outcome

The project demonstrates an end-to-end Data Science workflow,
from data preprocessing and exploratory analysis to Machine
Learning prediction and business insights.
